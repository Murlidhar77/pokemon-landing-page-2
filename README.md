# Pokémon Explorer 🎮

A Pokémon-themed landing page built using HTML and CSS. I created this project to practice building a structured website, working with layouts, and improving my frontend styling skills.

The design includes Pokémon cards, a search bar, a type filter, action buttons, and a footer with different sections. I also used custom fonts, icons, and Pokémon images to give the page its own look.

## ✨ Features

- Pokémon cards displaying names, Pokédex numbers, and types
- Search bar UI for finding Pokémon
- Dropdown menu for filtering by Pokémon type
- Favorite and view buttons on each card
- Header with menu, Pokémon logo, and theme button
- Custom icons, images, and typography
- Styled footer with Explore, Filter, Collection, and Stats sections
- Hover effects on buttons and footer items
- Custom favicon

## 🛠️ Technologies Used

- **HTML5** — Page structure, semantic elements, images, buttons, and form controls
- **CSS3** — Grid, Flexbox, spacing, borders, shadows, gradients, hover effects, and transitions
- **Custom Fonts** — Used a local WOFF2 font with `@font-face`
- **Local Assets** — Pokémon images, icons, and type graphics

## 📚 What I Learned

While building this project, I practiced:

- Structuring a webpage using semantic HTML elements such as `header`, `section`, `article`, and `footer`
- Organizing repeated content into consistent card layouts
- Using CSS Grid to arrange the Pokémon cards
- Using Flexbox to align icons, text, and buttons
- Styling buttons and cards with borders, rounded corners, and box shadows
- Adding hover and active states to make the interface feel more interactive
- Using CSS transitions for smoother visual effects
- Loading a custom font using `@font-face`
- Using descriptive `alt` attributes for images
- Connecting external CSS and organizing image assets in a separate folder
